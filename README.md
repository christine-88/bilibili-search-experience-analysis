Bilibili Search Experience Analysis
A product research project on learning-resource discovery, search result evaluation, and user experience improvement on Bilibili.​
1. Background
Users searching for learning resources need to identify content that matches their current skill level, learning goals, and available time. This project explores how search results communicate this information and how the experience could be improved.​
2. Research Questions
• Can users quickly identify resources suitable for beginners?​
• What information helps users decide which video to watch?​
• Where might users encounter friction when evaluating search results?​
• What product improvements could make learning-resource discovery easier?​
3. Research Plan
• Observe and record the first 10 results for selected search queries.​
• Evaluate titles, intended audience, course structure, practical exercises, and freshness information.​
• Compare the search experience with another content platform.​
• Collect feedback from users who have searched for learning resources.​
• Develop product recommendations supported by observations.​
4. Planned Deliverables
• Search result observation table​
• Competitor experience comparison​
• User research notes​
• Product improvement proposal​
• SQL practice using clearly labeled simulated data​
5. Project Status
Status: In progress​
Research findings and recommendations will be added as the work is completed.​
6. Data and Limitations
This project uses manually observed public search results. It does not use Bilibili internal data. Any simulated datasets will be clearly labeled, and conclusions will be limited to the evidence collected.​
